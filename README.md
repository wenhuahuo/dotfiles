# Personal Configuration File of OpenCode and NeoVim

## What's in it

### OpenCode

1. Agent
    - Answer Agent: agent with limited bash privileges and without edit privilege. It can answer questions well by the following workflows: 1. Anlyze the question. 2. Gather Information. 3. Synthesize Answer.

2. Skills
    - pdf: Modified from [Anthrophic pdf skill](https://github.com/anthropics/skills/tree/main/skills/pdf). To use this skill, you need a virtual environment called `skill`, and install `pypdf` `pdfplumber` and so on.
    - scitific-writing: Academic writing skill created by [K-Dense-AI](https://github.com/K-Dense-AI/claude-scientific-skills/tree/main/scientific-skills/scientific-writing).
    - AI-Vibe-Writting-Skills: Academic writing skill created by [donghuixin](https://github.com/donghuixin/AI-Vibe-Writing-Skills/).

3. Themes
    - VSCode-like theme: Simple theme generated by AI.

### NeoVim

1. Code Develop Plugins
    - [markview](https://github.com/OXY2DEV/markview.nvim.git): Markdown preview.
    - [illuminate](https://github.com/RRethy/vim-illuminate.git): Variable highlighting.

2. Theme Plugin:
    - [vscode](https://github.com/Mofiqul/vscode.nvim.git): VSCode-like theme for neovim.
