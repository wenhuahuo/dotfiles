## Core Style DNA
- **Tone**: Formal academic, technical and precise. Balances rigorous methodology with clear explanation. Both Chinese and English documents show strong academic register.
- **Sentence Pattern**: 
  - Chinese: Long, complex sentences with proper academic structure. Uses nested clauses and formal connectors (因此, 然而, 此外, 同时, 首先, 其次).
  - English: Clear, well-structured paragraphs. Standard academic English with technical precision.

## Do's (我要的风格)
- Use clear hierarchical structure with numbered sections (1., 1.1, 1.1.1)
- Include tables for data presentation and parameter specifications
- Provide mathematical equations with proper formatting (LaTeX/MathML)
- Use figure references with labels (如图所示, Figure X)
- Self-reference with "本项目", "本报告" in Chinese; "our model", "we" in English
- Start sections with clear topic sentences
- Use academic connectors: 因此, 然而, 此外, 同时 (Chinese); In addition, Therefore, However (English)
- Include model architecture descriptions with detailed parameter tables
- Provide quantitative analysis alongside qualitative discussion
- Use bullet points for listing key items (especially in proposals/applications)
- Include evaluation metrics and model performance details

## Don'ts (我不要的风格)
- Avoid overly casual language or slang
- Don't use vague terms without quantification
- Avoid starting consecutive sentences with the same word/phrase
- Don't omit technical details for "simplicity" - maintain rigor
- Avoid run-on sentences without proper punctuation
- Don't skip section headers or structural clarity
- Avoid inconsistent terminology within the same document
- Don't use excessive passive voice where active is clearer
